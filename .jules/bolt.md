## 2025-05-14 - [Reusing Audio instances and Hoisting static data]
**Learning:** In pages with large grids of interactive elements (like the Amharic alphabet with 200+ characters), creating a `new Audio()` object for each element or on every click causes significant memory pressure and garbage collection overhead. Wrapping leaf components in `React.memo` and using lazy initialization with `useRef` for heavy objects like `Audio` ensures smooth interactions. Additionally, hoisting static data like translations or large arrays outside of component definitions avoids redundant allocations on every render.
**Action:** Always check for opportunities to hoist static objects and memoize leaf components in high-density grids. Use lazy initialization for resource-heavy objects within components.
